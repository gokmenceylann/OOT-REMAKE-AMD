# Contributing

Use a branch and describe the tested scene, GPU, driver and settings in your pull request. Keep private game inputs, lifted code, generated EXE/image, cache and saves outside the checkout. Mako changes belong in the appropriate patch against the pinned submodule; preserve upstream license notices. Run the local package smoke test and apply-check the patches on a clean pinned submodule. Renderer changes should include Windows build and actual runtime results when available.
