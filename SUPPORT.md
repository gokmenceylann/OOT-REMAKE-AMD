# Support

Use the [issue chooser](https://github.com/gokmenceylann/OOT-REMAKE-AMD/issues/new/choose) for reproducible bugs, GPU results, performance reports and visual problems. Start with [known issues](docs/KNOWN_ISSUES.md) and [downloads](docs/DOWNLOADS.md) for setup questions.

GitHub Discussions is currently disabled. A repository maintainer can enable it from **Settings → General → Features → Discussions**. Suggested categories are Announcements, General, GPU Compatibility, Performance Reports, Development and Questions.

Include your build, exact driver and a short log excerpt. Remove personal paths, names and account identifiers. Keep game data, keys, dumps, saves and SDK binaries local.
