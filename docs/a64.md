# AArch64 statik derleyici

`python a64_compile.py input.bin generated.cpp --base 0x1000` ham little-endian A64 komutlarını C++20'ye çevirir. Python bağımlılıkları `requirements.txt` dosyasındadır. Üretilen kodu `a64_state.hpp` ile birlikte derle. `run_a64(state, budget)` ilk komuttan çalışır. X0–X30, SP, NZCV ve çağıranın sağladığı düz misafir bellek tamponunu kullanır.

ADD/SUB, mantık, karşılaştırma, MOV, ADR/ADRP, temel load/store, B/BL, koşullu dallar, CBZ/CBNZ ve RET için sınırlı biçimler uygulanır. Dal hedefleri verilen blokta olmalıdır. Bellek erişimleri sınır denetimlidir. Diğer komutlar derlemede hataya neden olur. Kod keşfi, SIMD, atomikler, sistem çağrıları ve tam oyun yürütme kapsam dışıdır.

Windows x64 hedefli Clang ve LLVM objcopy ile özgün test girdisi:

```powershell
clang --target=aarch64-none-elf -c tests_a64.S -o fixture.o
llvm-objcopy -O binary --only-section=.text fixture.o fixture.bin
python a64_compile.py fixture.bin fixture.cpp --base 0x1000
clang++ -std=c++20 -O2 -Wall -Wextra -Werror fixture.cpp tests_a64.cpp -o fixture.exe
.\fixture.exe
```
