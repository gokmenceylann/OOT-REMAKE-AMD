# Social preview

Design a 1280 × 640 image with safe margins around the text. Use **OOT-REMAKE-AMD** as the title, **Zelda: Ocarina of Time recomp** as the description, and **Vulkan · GPU compatibility** as supporting text. Use high contrast and a simple original background that remains readable at thumbnail size.

Use project text and original graphic elements. Omit Nintendo assets, vendor logos and partnership claims. In repository settings, use **General → Social preview** to upload the reviewed image. This guide supplies a layout direction for a future preview.
